# Timonier pour VSCode

Timonier permet de piloter des agents IA sans lire tout le code qu'ils produisent : architecture
vivante, tableau blanc d'intention, performances mesurées pendant les tests, plan et todo en direct.

**État : squelette (version 0.1.0).** L'icône Timonier (une barre à roue) de la barre
d'activité ouvre la vue d'ensemble. Son bouton « Ouvrir la carte », comme la commande
« Timonier : Ouvrir la carte », ouvre le panneau de la carte, encore vide. L'indexation et la
carte arrivent dans les prochaines versions.
